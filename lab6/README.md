## Описание

Контроль параметров промышленных лазеров: мощность излучения, длина волны,
частота импульсов, статусы ошибок оптики. В работе реализована полная
конвейерная обработка датасета на 2 000 000 записей с применением
векторизованных операций NumPy (без поэлементных циклов по строкам).

### Структура датасета

| Поле     | Тип      | Описание                       |
|----------|----------|--------------------------------|
| `ts`     | int32    | Время замера (UNIX-timestamp)  |
| `beam_id`| int16    | Идентификатор луча             |
| `power`  | float32  | Мощность излучения, Вт         |
| `wave`   | float32  | Длина волны, нм                |
| `pulse`  | float32  | Частота импульсов, Гц          |
| `err`    | uint8    | Код ошибки оптики (0–15)       |

---

## Реализованные этапы

1. **Загрузка** — `np.genfromtxt` в структурированный массив, контроль NaN/Inf
2. **Фильтрация и очистка** — булевы маски, `np.where`, `np.clip`
3. **Группировка по `beam_id` + Z-score нормализация** через `np.unique`
4. **Скользящее среднее `power` (k=25)** через кумулятивную сумму, `np.diff(pulse)`
5. **Feature Engineering** — `energy_per_pulse`, `eff_emission`
6. **Условная агрегация** по подмножеству активного режима
7. **Лаговые признаки** через `np.roll`, анализ знаков `np.sign` + `np.bincount`
8. **IQR-замена выбросов** внутри групп
9. **Проверка логической целостности** и сжатие редких категорий в `OTHER`

Акцент варианта: маска `err == 0` применяется до всех аналитических расчётов
(записи с ненулевым кодом ошибки считаются недостоверными).
