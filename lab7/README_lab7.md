## Описание

Интерактивная информационная панель (дашборд) для анализа параметров
промышленных лазеров. Реализована на Python с использованием
Tkinter (GUI), Matplotlib и Seaborn (визуализация), Pandas
(динамическая обработка данных).

Архитектура — событийно-ориентированная, без классов. Все операции
со структурой данных выполняются через `pandas`-вызовы, графики
строятся через `seaborn` поверх matplotlib и встраиваются в окно
Tkinter через адаптер `FigureCanvasTkAgg`.

---

## Возможности

- **5 типов графиков:** линейный, столбчатый, точечный, тепловая карта,
  гистограмма (все интерактивные)
- **Фильтрация:** по типу лазера и смене (Combobox)
- **Динамическая агрегация:** Mean / Sum / Median (RadioButtons)
- **Ресемплинг временного ряда:** День / Неделя / Месяц / Год
- **Сглаживание скользящим средним** (Checkbox)
- **Экспорт** текущего графика в PNG / PDF
- **Тулбар matplotlib:** зум, панорамирование, сохранение, сброс

## Запуск

```bash
python -m pip install pandas matplotlib seaborn
python dashboard.py
```

Если файла `data_dashboard.csv` нет, его можно сгенерировать заново
(нужен исходный `data_variant_16.csv` из лабораторной работы №6):

## Структура датасета

К исходным числовым полям из лабораторной работы №6 добавлено
4 категориальных признака:

| Поле          | Тип       | Источник / описание                            |
|---------------|-----------|------------------------------------------------|
| `date`        | datetime  | Из `ts` (UNIX-timestamp)                       |
| `shift`       | category  | Смена: morning / day / night, по часу замера   |
| `laser_type`  | category  | Тип лазера: CO2, Nd:YAG, Fiber, Diode, Excimer |
| `status`      | category  | Статус замера: OK / WARNING / ERROR            |

## Применённые методы pandas

| Задача интерфейса         | Метод pandas                |
|---------------------------|-----------------------------|
| Динамический фильтр       | `df.query()`                |
| Смена типа агрегации      | `df.groupby().agg()`        |
| Скользящие тренды         | `df.rolling().mean()`       |
| Агрегация по периодам     | `df.resample()`             |
| Биннинг гистограмм        | `pd.cut()`                  |
| Подготовка матриц         | `pd.pivot_table()`, `df.melt()` |
